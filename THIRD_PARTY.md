No blanket license for all repository contents is implied. A license for newly authored project code has not yet been selected. Third-party materials retain their own terms; model weights, upstream code and audio are not bundled here.

| Source | Use and attribution |
| --- | --- |
| [AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/corpus/overview.shtml) | Original speech, transcripts and meeting metadata. The supplied corpus/annotations identify CC BY 4.0. The replay bundle retains `data/LICENCE.txt`, `data/CCBY4.0.txt` and the release 1.7 README. Development text is segmented/normalized from manual annotations; the evaluation manifest derives from the HF AMI-Cleaned variant. |
| [HF Open ASR Leaderboard data](https://huggingface.co/datasets/hf-audio/open-asr-leaderboard) | AMI-Cleaned evaluation references and embedded audio source; dataset revision `de79e57adf9983993bcc72586d7313460825f5eb`. | Brown Corpus, W. N. Francis and H. | OpenAI Whisper large-v3 / large-v3-turbo; NVIDIA Parakeet TDT 0.6B v3 | Models run through the specified upstream backends. Checkpoints/revisions are in `configs/inference_smoke.json`. Obtain weights separately under their model-card terms; model weights are excluded from Git and the replay bundle. |

Published comparison scores in `configs/leaderboard_reference.json` were supplied by the user from the leaderboard and were not independently mapped to historical revisions. New model predictions were generated by our pinned inference runs. Raw references and source text are preserved where required for replay, with normalization treated as a derived view.

For the original AMI dataset description, see J. Carletta et al., *The AMI Meeting Corpus: A Pre-announcement* (2005), and the corpus website for current citation guidance. Consult source licenses before redistributing additional audio, annotations, weights or upstream software beyond this package.
